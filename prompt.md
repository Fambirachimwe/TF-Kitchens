# ANIMATION RULES

Use Framer Motion sparingly.

Allowed:
- Fade up
- Fade in
- Subtle scale
- Image zoom on hover
- Card hover lift

Avoid:
- Excessive motion
- Heavy parallax
- Bouncing animations

Transitions:
0.3s–0.5s
